## Por que foi feito

O projeto não possuía nenhuma documentação. O README.md é a porta de entrada de qualquer lib open-source — precisava ser visualmente impactante, tecnicamente preciso e didático o suficiente para que qualquer dev entenda o valor da lib em segundos.

A abordagem foi criar um README que funcione como um "mini-site" usando markdown puro: badges para credibilidade, diagramas ASCII para clareza arquitetural, tabelas comparativas para demonstrar valor, e exemplos progressivos do básico ao avançado.
